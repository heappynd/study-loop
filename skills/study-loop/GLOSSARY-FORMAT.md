# GLOSSARY.md 格式

`GLOSSARY.md` 是这个教学工作区的规范用语，发布于 `/GLOSSARY`。课程、速查页、learning record 都遵守这里的术语。写术语表本身就是学习的一部分：把一个概念压成一句紧的定义，是理解它的证据。

## 结构

```md
# {主题} 术语表

{一两句话说明这份表覆盖什么。}

## 肌肉与训练

### 肌肥大（Hypertrophy） {#hypertrophy}

在反复训练中由机械张力与代谢压力驱动的肌肉增长。

_Avoid_: 增肌期、变壮

### 渐进超负荷（Progressive overload） {#progressive-overload}

系统性地提高对肌肉的要求——负荷、容量或强度。

_Avoid_: 加练、升级
```

## 规则

- **锚点必须手写。** VitePress 只给**标题**自动生成锚点，粗体正文不会。每个术语用 `### 名称（English） {#slug}` 形式，`{#slug}` 是课程里 `/GLOSSARY#slug` 链接的依据。漏了它，该链接就是死链，`course:check` 会报错。
- **用户理解了才收。** 术语表记录的是压缩后的知识，不是给人从头读的词典。等他能正确使用这个词再写。
- **要有主张。** 一个概念有多个叫法时，选最好的那个，其余放进 `_Avoid_`。语言就是这样被压缩的。
- **定义要短。** 一两句。定义这个术语**是什么**，不是它有什么用、怎么用。
- **用表里的词解释表里的词。** 一旦某个词进来，所有地方（包括其他定义里）都优先用它。
- **聚类就分节。** 术语成簇时用 `## 分组`；彼此紧密相关时平铺一层也行。
- **歧义要显式解决。** 领域里用法混乱时写清楚：「本课程中『组』一律指正式组，热身单独计。」

## 在站点里

每个术语靠 `{#slug}` 得到锚点，课程用 `/GLOSSARY#slug` 链接。**优先链接，而不是在课里重复定义。** 这一页会发布，保持面向读者：没有 agent 笔记，没有「待核实」。
