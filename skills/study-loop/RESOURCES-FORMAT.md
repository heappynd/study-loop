# RESOURCES.md 格式

`RESOURCES.md` 是这个主题的可信来源清单。课程里的知识从这里取，**绝不来自模型记忆**。「智慧」来自这里列的社区。

这个文件不参与站点构建（`srcExclude`），是给 agent 看的状态，裸链接和工作笔记都可以。

## 结构

```md
# {主题} 资源

## 知识

- [书：《The Science and Practice of Strength Training》Zatsiorsky & Kraemer](https://example.com)
  训练编程的基础教材。用于：周期化、恢复、强度区间的一切判断。checked: 2026-10-22
- [文章："How Much Should I Train?" Greg Nuckols（Stronger By Science）](https://example.com)
  容量地标的循证综述。用于：各肌群每周组数目标。checked: 2026-10-22

## 智慧（社区）

- [r/weightroom](https://reddit.com/r/weightroom)
  高信噪比，版规禁止伪科学。用于：计划点评、平台期排查。
- 线下：周二力量课（{健身房名}）
  用于：动作的实时纠正。

## 缺口

- 「{.}」还没有可信来源：需要找 {什么算高可信}。
```

## 规则

- **只要高可信。** 一手资料、公认专家、同行评审、强管理的社区。伪装成教学的营销内容一律不收。
- **每条都要注解。** 一行说清覆盖什么、什么时候该翻它。光秃秃的链接三个月后就没用了。
- **每条都要有 `checked:` 日期。** 格式 `checked: YYYY-MM-DD`。快速变化的领域（框架、库、法规）超过 6 个月就要重新核对——课程里写下的「最新特性」半年后通常是错的。
- **按知识 / 智慧分组。** 对应 `SKILL.md` 里的理念。一个来源只能出现在一组。
- **把缺口写出来。** mission 需要但找不到好来源时，写 `## 缺口`。它会驱动下一次搜索。
- **狠心删。** 错误、浅薄、偏离 mission 的来源要删掉，不是埋起来。五个锋利的来源胜于三十个平庸的。

## 在课程里

课程的 `sources` frontmatter 与 `<Source>` 块必须指向本文件里已有的条目。要引用没登记过的来源，**先加到这里，再引用**。这样课程的可信度是可审计的。

`course:check` 会校验这条：课程里出现的每个来源 URL 都必须在本文件里出现。
